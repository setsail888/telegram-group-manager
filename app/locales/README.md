# 界面语言包

`app/i18n.py` 中的 `LOCALES` 是可选语言清单。中文使用源码文案，其他语言以中文源模板为键、本地译文为值。机器人运行时仅加载这些文件，不联网翻译，也不发送聊天内容给翻译服务。

新增24种语言以现有英文文案为基础，使用机器辅助翻译，保护格式占位符、命令、网址和中文关键词示例。它们覆盖与英文相同的全部系统文案，但尚未逐项经过母语者校对；术语和语气可以继续修订。用户自定义欢迎语、群规、公告、关键词、奖励名称与聊天内容不在翻译范围。

维护时修改对应JSON值，保留键与占位符。新增或修改源码文案后，为每种语言补齐译文，再运行：

```bash
python scripts/prepare-i18n.py --check
python -m unittest tests.test_i18n tests.test_panel_languages -v
```

检查器会验证所有可选语言的文案覆盖和占位符，不把缺译的语言按钮提前展示给用户。
