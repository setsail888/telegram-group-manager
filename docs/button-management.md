# 中文按钮管理与防护调优

## 管理员入口

把机器人加入群并授予所需管理权限后，私聊机器人 `/start`，选择群组。每次按钮点击都会重新核验该群管理身份。

| 页面 | 可直接操作 |
| --- | --- |
| 智能反垃圾 | 伪装链接、显式/隐藏提及、拆字识别、累计禁言、观察模式、外部频道拦截、阈值调整、文字测试 |
| 防刷屏 | 消息条数/时间、重复判断、媒体频率、相册合并计数、删除/临时禁言、自动撤回提醒 |
| 违禁词 | 添加/删除、批量输入、文件导入预览、分段导出、搜索与分页、逐词包含/整词/整句匹配、拆字开关、精确例外、文字测试、处罚及提醒 |
| 分类词库 | 13类6,566条去重词条，含73个两字词，逐类关闭/观察/处罚、定向分类先观察、分页查看、单词排除/恢复 |
| 中文变体识别 | 繁简字形、定向同音/拼音、短词拆字增强分别关闭/观察/处罚，预览确认，显示识别类型 |
| 集中入群防护 | 自动检测开关、入群人数/窗口/保护时长、预览确认后立即开启/停止、当前保护期限 |
| 权限检查 | 机器人管理身份、群类型、删除/限制权限、OCR引擎及刷新 |
| 新人验证 | 开关、时限、答错上限；答错用尽保持受限，超时移出后允许重进 |
| 新成员限制/机器人/转发/图片 | 独立开关；昵称长度、图片重复条数和时间可用加减按钮调整 |
| 欢迎消息 | 开关、编辑欢迎语和群规、每分钟欢迎上限；欢迎语支持 `{name}` |
| 域名白名单 | 分页查看、批量添加、确认删除；精确域名及其子域名放行 |
| 自动回复 | 分页查看、分步添加/替换、确认删除；文字或直接发媒体、最多三个 HTTPS 按钮；全群每分钟总限频 |
| 定时公告 | 分步创建单次/每日/每周公告；使用页面显示的时区；查看、暂停/恢复、确认删除 |
| 积分签到 | 开关、基础奖励调整、排行榜、管理员加/扣积分 |
| 商城 | 上架虚拟奖励、分页查看/下架、最近40笔待处理订单、确认核销/退款 |
| 免费抽奖 | 创建、查看、确认开奖/取消；开奖时复核候选成员，单次最多三人；开奖结果保存，不能重抽 |
| 成员管理 | 警告/清除、禁言/解禁、封禁/解封、移出可重进；输入数字ID后预览确认 |
| OCR | 关闭/仅审核/自动删除、可信度调整；需部署本地 Tesseract 并启用 OCR |
| 防护记录 | 分页查看时间、消息ID、目标ID、原因、命中词条/分类、成功/失败/观察状态、标记已复核 |
| 管理日志 | 设置/关闭独立日志群，检查双边管理身份及机器人发消息权限 |
| 统计/排行/总览 | 今日、近7天、活跃榜、当前规则状态 |

新表单按「选择功能 → 分步发送内容 → 操作预览 → 确认」执行；十分钟内有效。`/cancel` 或返回其他管理页面会取消草稿。确认只执行一次；机器人重启后应重新填写。长公告预览会分段显示，最后一段才有确认按钮。

已有命令继续可用。违禁词原有编辑流程保留即时保存方式，结果下方提供返回按钮。手动管理及新人验证独立于内容过滤观察模式。

成员数字ID可让成员私聊机器人 `/id` 查看；管理员也可在群内回复目标消息后发 `/id`。日志目标 ID 在目标群发 `/id` 查看。

## 成员入口

成员在群中发送 `/menu`，点击「成员服务」打开该群的私聊页面，可签到、查看积分/排行/个人订单、兑换奖励、报名免费抽奖、看群规和自己的ID。所有点击都会核验当前群成员身份，未完成新人验证者无法使用。

兑换先展示商品、所需积分和人工核销说明，确认才原子扣分及扣库存。确认五分钟有效，绑定本人、群组和原始确认消息；重复点击不会重复扣分。返回或取消会撤销确认，商品/库存变化后需要重新预览。普通命令订单与私聊按钮订单使用分离的请求编号，避免不同私聊中的同号消息互相冲突。

积分转赠继续使用群内回复对方 `/transfer 数量`，再点击确认。抽奖为免费报名，不扣积分、不收费。商城奖励由管理员人工核销。

## 三项重点防护

1. **违禁词**：旧词默认按规范化子串识别；词库中可逐词选择包含、整词或整句。包含模式可选拆字识别，短词另选“中文变体识别 → 短词拆字增强”。精确例外仅豁免对应关键词与完整允许文本；额外广告文字或其他违规词仍会触发。OCR 同样使用定向完整文本例外，并保留可信度及至少四字的保守门槛。
2. **智能反垃圾**：规则引擎检查文字/图片说明、URL 实体、隐藏链接、按钮文字/链接、伪装网址及批量提及。白名单只按完整域名及子域名放行。不是调用大模型的语义审核。新增「外部频道发言拦截」默认关闭，开启后拦截所有外部频道身份发言；本群匿名管理员和关联频道的自动转发保留。不会对 Telegram 的频道代发虚拟用户执行禁言。
3. **防刷屏**：按成员分别检查条数、完整文本摘要、媒体频率和相同图片，编辑不增加次数，可用消息ID在窗口内去重。可选相册合并只影响消息条数和媒体次数，每张图片说明仍独立检查，文本重复规则仍生效。默认继续逐条计算。

建议从「智能反垃圾 → 仅观察内容过滤」开始调参。观察命中不会删帖、禁言或加入累计违规处罚历史，普通业务命令继续按自身规则执行。确认阈值后关闭观察，恢复原有处罚。新人验证、昵称限制、机器人清退、管理员手动操作继续各自生效。

防护记录只存元数据，不保存聊天原文或图片，保留30天、每群最多1000条；同消息同来源重投不会新增多条记录。查看原消息需要群访问权限，已删除消息无法打开或恢复。「已复核」只作标记，调规则请通过白名单、关键词例外或阈值按钮。

自动回复保留每人每规则60秒冷却，并增加默认每群每分钟20条的总限制，可调1–60条；防止多人触发放大群内消息。新人验证默认允许答错3次，可调1–5次，次数持久化。

## 词库搜索与匹配方式

「违禁词 → 查看词库」或「搜索词库 → 发送搜索文字」，点击条目，再选择匹配方式或删除，预览后确认。列表及搜索按钮仅对本人/该群有效，十分钟到期；多个管理员修改同一规则时，旧预览会被拒绝。重新添加已有词会保留其匹配方式，删除后重新添加则恢复包含模式。

| 模式 | 示例与范围 |
| --- | --- |
| 包含 | `ad` 会命中 `bad`；适合明确的广告短语。遵循拆字开关 |
| 整词 | `ad` 命中 `ad!`，不会命中 `bad`、`ad_1` 或 `汉ad字`。两侧必须没有相邻字母/数字/下划线/汉字，不进行中文分词 |
| 整句 | `联系客服` 仅命中完整相同文字，前后多加其他字不命中；适合精确短句 |

三种模式均规范化大小写、全半角及零宽字符。整词和整句不使用拆字开关；OCR 的整句比较会合并识别产生的空格/标点，因此先用「仅审核」验证真实图片。词库搜索按字面文字查询，`%`、`_` 不会被当作搜索通配符。正文、图片说明及可见按钮文字都参与规则检查。

## 分类词库和文件导入

「违禁词 → 分类词库」可逐类查看词条，选择关闭、仅观察或执行处罚，预览后确认。13类均默认关闭；定向分类组合只开启观察。点击词条可从本群内置词排除，或在首页输入完整词恢复；同名自定义规则优先，精确例外也适用。防护记录显示命中词及分类，分类观察不会放过独立的外链或刷屏违规。

「违禁词 → 中文变体识别」单独设置繁简、定向同音/拼音、短词拆分，三项默认关闭。先启用目标分类或添加自定义包含词，再点击“三项全部先观察”并测试。`刷單`、`唰单`、`shuadan`、`刷⭐单`可命中对应规则，`菠菜`需附近博彩提示词。只有包含模式扩展；组合所需功能或分类任一为观察就仅观察，全局观察及总开关优先。新设置持续保存，十分钟限制只用于预览确认；确认前再次检查权限、设置状态和词库版本。范围及误判边界见 [词库指南](word-library.md#两字词繁简与同音绕过)。

「文件导入」支持UTF-8逐行词、匹配方式加Tab或JSONL，单文件1 MiB、词库总条数不限，先展示新增/保留/重复数量再确认；已存在的规则不覆盖。导出为保留模式/显示名的JSONL，超过一部分时点击下一部分。分类数量、格式、来源及误判说明见 [词库指南](word-library.md)。

## 集中入群防护

「集中入群防护」默认关闭，初始阈值为 **60秒内10个不同普通成员入群 → 保护10分钟**；人数可调3–100，窗口10–300秒，时长1–60分钟。需超级群组及机器人限制成员权限。

触发者和保护期内后续新人需完成原有验证题，遵循「新人验证」页的时限/答错次数设置；不追溯之前的成员。管理员、其他机器人及已有个人限制的成员不计入触发人数，不用验证题覆盖现有限制。重复入群通知不重置已有验证题或答错次数，无法核验身份时跳过自动限制。保护期限持久化，入群计数是有容量上限的内存窗口，重启后重新累计。

「立即开始保护」与「停止额外保护」均需预览确认。自动检测开关只控制今后的触发，关闭它不会取消已有保护。保护到期或手动停止后，不再对后续新人追加验证；已经收到题目的成员仍需验证或等待超时清理。常规「新人验证」开关独立，开启时仍持续要求新人验证。内容过滤的观察模式不暂停入群验证。

「欢迎消息」默认每群每分钟最多10条，可调1–60；超出时略过欢迎语，不延迟补发。验证题单独发送，不占欢迎额度，避免新人因看不到题目被困住。

## 部署与验证边界

数据库升级为增量建表/加字段，保留旧设置、积分、订单、抽奖及待验证成员。升级前仍应按 README 备份；更新代码后重新构建容器。当前工作未连接真实 Telegram 群或生产数据库，中文按钮、权限和业务链路由离线 API 替身测试验证。真实群权限、网络延迟、OCR 图片质量和服务器备份恢复仍须实际验收。

界面采用 Telegram 原生按钮和消息表单。浏览器看板仍为只读统计页，没有新增网页写入接口。

设计参考公开资料：[Rose 防刷屏](https://missrose.org/docs/anti-spam/antiflood/)、[Rose 高级关键词](https://missrose.org/docs/anti-spam/blocklists/advanced/)、[Group Help 官方频道](https://t.me/s/GroupHelp)。`@WeGroupCloneBot` 的公开网页未能读取，因此没有将无法核实的能力列作参考依据。
