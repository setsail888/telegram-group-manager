# 成员按钮入口

成员不必记住全部命令。群内发送 `/menu`，点击 **成员服务**，进入对应群的私聊菜单。

| 按钮 | 点击后的作用 | 使用条件 |
| --- | --- | --- |
| 签到 | 领取本群当日积分，重复签到不重复加分 | 管理员开启积分，且本人完成新人验证 |
| 积分 / 排行 | 查询本群余额、积分排名 | 当前群成员，可查看已保存数据 |
| 商城 | 查看奖励，预览后确认兑换 | 兑换需积分开启、余额足够、奖励已上架且有库存 |
| 订单 | 查看本人最近20笔订单与状态 | 本群已有个人订单 |
| 抽奖 | 查看当前活动，另外点击报名才算参与 | 管理员先创建活动；免费，不要求积分开启 |
| 群规 | 阅读管理员保存的群规 | 不要求欢迎消息开启 |
| 我的ID | 查看本人数字用户ID和当前群ID | 不要求积分开启 |
| 界面语言 / Language | 切换自己的私聊语言 | 不改变群语言或其他成员的选择 |

首次进入需按Telegram提示启动私聊。每次点击会核验当前群成员身份，未完成新人验证或已经离群的用户不能使用。

成员服务及各功能页的 **📖 功能说明** 介绍使用条件和示例；首页说明还可进入签到积分、商城、抽奖、群规与ID的专门说明，无需先签到或报名。返回说明对应页面只查询，不重复签到、下单或报名。兑换预览中打开说明会取消本次确认，返回商城后重新选择奖励；说明与按钮跟随个人中文 / English 设置。

## 功能不可用时

签到和兑换需要管理员先开启积分；商城需先上架奖励；抽奖需先创建活动。没有活动或奖励时，不会凭空创建。

私聊按钮入口与群组绑定，不同群余额、订单和报名独立。积分转赠仍在群内回复接收者发送 `/transfer 数量`，再点击确认。

成员服务菜单本身不是一键启用全部功能。管理员未开放签到、没有上架奖励或没有创建抽奖时，按钮只会展示对应状态，不会代替管理员创建内容。
