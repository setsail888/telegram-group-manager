# 签到积分与转赠

## 各功能有什么用

| 功能 | 开启或操作后的作用 |
| --- | --- |
| 签到积分开关 | 开启成员签到，也允许积分转赠和商城兑换；关闭后保留余额和历史订单 |
| 签到基础奖励 | 决定每日签到的基础积分，不是每发一条消息的奖励 |
| 连续签到奖励 | 连续签到额外加分，第二天加1分，最多加6分；不需要另开开关 |
| 积分 / 排行 | 查看本群余额和积分排名，不代表聊天活跃度排名 |
| 调整成员积分 | 管理员给指定成员加分或扣分，不要求成员发送关键词 |
| 积分转赠 | 将自己的积分转给同群已验证成员，确认后才扣分 |
| 积分流水 | 查看加分、扣分、转赠和兑换等记录，帮助核对余额变化 |

只开积分即可签到，不必开启智能反垃圾或商城。开启积分不会自动上架奖励、创建抽奖，也不会按发言次数自动加分。免费抽奖不依赖积分开关。

## 管理员开启积分

**入口：积分签到 → 签到积分。** 默认关闭，开启后调整签到基础奖励，初始5分，可调1–100。

群内命令：

```text
/pointmode on
/pointrate 5
```

关闭积分不会清空已有余额。积分按群组和成员ID分别保存。

## 成员签到和查询

通过[成员菜单](menu.md)点击签到，或群内发送 `/checkin`。按机器人配置的时区计算自然日，默认北京时间，每天一次。

连续第二天额外1分，第三天额外2分，最多额外6分；中断后重新累计连续天数。`/points` 查询余额，`/pointtop` 查看本群前10名。

按初始基础奖励5分计算：连续第1天得5分、第2天6分、第3天7分，第7天起每天最多11分；同一天重复点击不会再得分。签到按自然日跨日，不是距离上次签到满24小时。

关闭积分后，群内签到、余额和排行命令不会继续公开回复；本人私聊成员菜单仍可查询余额、排行和订单。管理员调分、核销或退款可继续处理原有记录，不会因开关关闭而清空。

## 管理员调分

积分签到 → **调整成员积分** → 输入成员数字ID → 输入正数增加/负数扣除 → 预览确认。单次不超过10000分，不能扣成负数。

群内回复成员消息发送 `/pointadd 20` 或 `/pointtake 20`，`/pointlog` 查看流水。调分成功不会额外在群内播报处罚式提示，但保留本地记录。

## 同群积分转赠

回复接收者的普通消息，发送：

```text
/transfer 20
```

机器人展示确认与取消按钮，只有发起者可点击。**确认前不扣分，确认请求5分钟有效。** 执行时复核双方成员身份和余额，重复点击不重复扣分。

每次最多1000分，不能转给自己、机器人或其他群成员。成员需完成新人验证，积分功能需开启。

## 积分能兑换什么

用于本群[虚拟奖励商城](shop.md)。没有提现、现金兑换或加密货币转账功能，奖励由管理员人工核销。
