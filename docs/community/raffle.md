# 免费抽奖

**管理员入口：免费抽奖。成员入口：成员服务 → 抽奖。** 免费报名，不扣积分、不收费；每群同一时间只有一个开放活动。

## 创建活动

1. 管理员点击 **创建免费抽奖**。
2. 输入2–100字的标题，检查群组和标题后确认。
3. 告知成员使用抽奖菜单或 `/joinraffle` 报名，一人一次。

群内也可使用 `/rafflestart 活动名称` 创建，`/raffle` 查看。

## 开奖与取消

管理员查看活动，选择开奖，核对预览后确认；取消也需确认。群内命令分别为 `/raffledraw`、`/rafflecancel`。

开奖前会复核随机候选的在群和验证状态；发现失效候选时清除报名再选，单次最多尝试三人，身份查询异常时不会直接判定中奖。没有完成开奖时，先检查提示再重试。

## 结果和限制

中奖结果保存到数据库，用 `/rafflehistory` 查询，不提供已开奖活动重抽。收到退群事件后会取消开放活动中的报名，开奖还会再次复核。

随机选择不替代管理员核实活动资格与履行奖励承诺。功能不提供投注、现金兑奖或自动发奖。
