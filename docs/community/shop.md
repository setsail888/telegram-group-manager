# 商城与订单

**管理员入口：积分商城。成员入口：成员服务 → 商城 / 订单。** 使用本群积分兑换管理员上架的虚拟奖励。

## 各功能有什么用

| 功能 | 操作后的作用 |
| --- | --- |
| 上架奖励 | 设置成员可兑换的项目、积分价格、库存和人工领取说明；不会直接给成员发奖 |
| 查看奖励 / 兑换预览 | 展示本次价格和说明，不立即扣分 |
| 确认兑换 | 复核成员身份、积分开关、余额和库存，扣积分、减1份库存并生成待核销订单 |
| 核销订单 | 管理员确认已人工发放，订单改为已核销；不再扣一次积分 |
| 退款订单 | 未核销订单退回原扣积分并恢复1份库存；不支持对已核销订单再次退款 |
| 下架奖励 | 停止新兑换，保留历史订单；已有待核销订单仍需核销或退款 |
| 我的订单 | 查看本人在当前群的兑换及处理状态，不显示其他成员订单 |

只上架奖励、未开启积分时，成员不能完成兑换。开启积分后也需要成员有足够余额和商品有库存；库存为0表示售罄，不是无限库存。

## 管理员上架奖励

点击上架入口，依次填写名称、价格、库存和说明，检查预览后确认。每群最多30个同时上架奖励。

| 字段 | 范围 |
| --- | --- |
| 名称 | 2–60字 |
| 单价 | 1–10000积分 |
| 库存 | 1–1000 |
| 说明 | 最多300字 |

命令示例：

```text
/shopadd VIP群内头衔 | 30 | 5 | 管理员核实后手动设置群头衔
```

上架头衔不代表机器人会自动授予权限，请在说明写清人工处理方式。

## 成员兑换

打开商城选择奖励，查看价格与人工核销说明，点击确认才扣积分和库存、生成待处理订单。确认5分钟有效，重复点击不会重复扣除；价格或库存变化后需要重新预览。

群内 `/shop` 查看，`/buy 商品编号` 是直接兑换命令，会立即扣分并生成订单；需要先确认时优先使用成员按钮。`/myorders` 查看自己的订单。

例如余额100分、奖励价格30分、库存5份：查看预览时仍为100分；确认后余额70分、库存4份、订单待核销。管理员退款后恢复100分和5份库存；核销则仅改变订单状态，不再次扣分。

## 管理员核销和退款

商城管理可查看最近40笔待处理订单，选择订单后确认核销或退款。

- **核销**：只记录已人工完成发放，不会自动设置头衔或发送奖励。
- **退款**：仅限未核销订单，退还积分并恢复库存；已退款不能重复处理。
- **下架**：停止新的兑换，不自动撤销已有订单。

命令：`/shoporders`、`/shopdone 订单号`、`/shoprefund 订单号`、`/shopremove 商品编号`。

商城没有现金支付、现实商品结算或自动发货。完整配置和订单通过数据库备份保存。
