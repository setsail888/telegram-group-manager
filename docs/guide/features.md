# 全部功能导航

管理员统一入口：**私聊机器人 `/start` → 选择群组**。下表的路径从该群管理菜单开始；成员服务和服务器命令另有入口。

界面可自由切换[简体中文 / English](languages.md)：私聊 `/language` 修改个人语言；管理员在群菜单的“群内提示语言”修改当前群语言。

本页先说明每项功能能做什么，点击入口可查看作用表、参数示例、操作步骤和开关关系。

机器人各功能页也提供 **📖 功能说明**：在私聊中查看用途、当前群的参数示例、开关关系和处罚范围，点击 **返回本功能** 继续操作，或点击 **在线详细文档** 打开对应教程。支持中文 / English，阅读不修改群配置或执行处罚。

## 先看开关之间的关系

| 设置 | 实际控制范围 |
| --- | --- |
| 智能反垃圾主开关 | 批量提及，以及同时开启链接拦截时的伪装网址增强；不是全部群防护的总开关 |
| 违禁词总开关 | 自定义词、已启用分类与中文变体的关键词检查；OCR也依赖它 |
| 防刷屏主开关 | 个人频率、重复文字，以及另行启用的媒体连发和跨账号检测；图片防刷独立 |
| 仅观察内容过滤 | 让内容过滤命中只记录，不自动删帖或执行对应处罚；不暂停新人验证、手动管理和群运营 |
| 积分开关 | 签到、积分转赠和商城兑换；不要求免费抽奖同时开启 |

同一消息可被多个独立模块检查。关闭一项只关闭该项；某分类仅观察，也不保证消息不会因另外的链接或刷屏违规被处理。各群配置独立，更新程序保留已有设置。

::: tip 不确定现在开了什么
进入当前群的 **规则总览** 查看开关与参数，再到 **防护记录** 看实际命中原因。操作预览的“十分钟内有效”只是确认期限，确认后的配置持续保存，见[时间说明](permissions.md#设置怎么保存)。
:::

## 违禁词、反垃圾与防刷屏

| 功能 | 开启或操作后的作用 | 入口与详细用法 |
| --- | --- | --- |
| 自定义关键词 | 按包含、整词或整句匹配已配置词；可先测试，再删除或禁言 | [违禁词](../moderation/keywords.md) |
| 13类内置词库 | 按类别启用现成词条，可观察、处罚或排除不适合的词 | [违禁词 → 分类词库](../moderation/word-packs.md) |
| 中文变体识别 | 扩展基础包含词的繁简、拆字、多音字混写、拼音缩写和部分同音写法 | [违禁词 → 中文变体识别](../moderation/variants.md) |
| 导入、导出与例外 | 迁移自定义词，或允许指定规则对完整正常文本的命中 | [违禁词 → 导入 / 导出 / 例外](../moderation/import-export.md) |
| 智能反垃圾 | 检查超量提及；配合链接拦截识别部分伪装网址 | [智能反垃圾](../moderation/anti-spam.md) |
| 链接拦截 | 检查普通、隐藏和按钮网址；不自动判断网站是否安全 | [链接管理 / 智能反垃圾](../moderation/anti-spam.md#能检查什么) |
| 域名白名单 | 放行指定域名及真实子域名的链接，不豁免关键词和刷屏 | [域名白名单](../moderation/anti-spam.md#域名白名单) |
| 转发与频道身份 | 分别限制带转发来源的消息、外部频道代发身份 | [禁止转发 / 智能反垃圾](../moderation/anti-spam.md#转发和频道身份) |
| 个人防刷屏 | 检查同账号消息频率、相同文字，及另开开关的媒体连发 | [防刷屏](../moderation/anti-flood.md) |
| 图片与相册 | 检查重复图片；可让同一相册在频率统计中算一组 | [图片防刷 / 防刷屏 → 媒体连发](../moderation/anti-flood.md#图片与相册) |
| 跨账号重复 | 同内容消息数、人数同时达标后，清理缓存消息，只处罚当前触发者 | [防刷屏 → 跨账号重复](../cross-account-flood.md) |
| 防刷屏惩罚 | 设置命中后的警告、禁言、踢出、封禁或仅撤回；不自动开启检测 | [防刷屏 → 惩罚](../moderation/penalties.md) |
| 累计自动禁言 | 按同成员10分钟内实际删帖累计处理，不等于每次违规立即禁言 | [智能反垃圾 → 自动禁言](../moderation/anti-spam.md#累计违规禁言) |
| 图片文字识别 | 本机OCR识别照片文字，符合条件后审核或删除；需服务器部署引擎 | [图片 OCR](../moderation/ocr.md) |

## 入群与成员

| 功能 | 开启或操作后的作用 | 入口与详细用法 |
| --- | --- | --- |
| 新人验证 | 新加入的普通成员答题后解限，超时移出且允许重进 | [新人验证](../members/verification.md) |
| 集中入群防护 | 入群人数短时达标后，对触发者与后续新人暂时要求验证 | [集中入群防护](../members/raid.md) |
| 昵称限制 | 超长昵称新人临时禁言30分钟，不持续检查所有成员改名 | [新成员限制](../members/management.md#超长昵称限制) |
| 机器人防护 | 清退新加入的其他机器人，不扫描群内原有机器人 | [机器人防护](../members/management.md#其他机器人入群) |
| 手动成员管理 | 管理员指定成员后警告、禁言、移出、封禁或解除 | [成员管理](../members/management.md#手动管理成员) |
| 权限检查 | 查看群类型及机器人管理权限，不自动授予缺失权限 | [权限检查](permissions.md#机器人需要哪些权限) |

## 群运营与成员服务

| 功能 | 开启或操作后的作用 | 入口与详细用法 |
| --- | --- | --- |
| 欢迎语与群规 | 发送新人欢迎语，提供群规查询；不把群规自动转成处罚规则 | [欢迎消息](../operations/welcome.md) |
| 自动回复 | 普通成员文字包含配置关键词时，发送预设文字或媒体 | [自动回复](../operations/replies.md) |
| 定时公告 | 按单次、每日或每周计划发送文字，可暂停或删除任务 | [定时公告](../operations/schedules.md) |
| 统计与活跃排行 | 查看今日、近7天数据及有效文字消息排行，不读取过去群历史 | [今日统计 / 最近7天 / 活跃排行](../operations/statistics.md) |
| 规则总览 | 查看当前群开关和参数，不修改配置 | [规则总览](../operations/statistics.md#各页面有什么用) |
| 防护记录与日志 | 核对命中、删帖及处罚结果，可将管理事件发送到独立日志群 | [防护记录 / 管理日志](../operations/statistics.md#防护记录) |
| 签到积分与转赠 | 每日签到得分，管理员调分，成员确认后向同群成员转赠积分 | [积分签到](../community/points.md) |
| 积分商城 | 兑换管理员上架的虚拟奖励，扣分生成订单，由管理员核销或退款 | [积分商城](../community/shop.md) |
| 免费抽奖 | 免费报名，管理员手动随机选出1名获胜者；不扣积分 | [免费抽奖](../community/raffle.md) |
| 成员按钮入口 | 让成员在私聊中签到、兑换、报名及查询个人记录 | [群内 `/menu` → 成员服务](../community/menu.md) |
| 界面语言 | 独立设置个人私聊语言和群内提示语言，自定义内容保留原文 | [界面语言 / 群内提示语言](languages.md) |
