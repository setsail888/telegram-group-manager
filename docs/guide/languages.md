# 界面语言切换

机器人目前提供 **简体中文、English** 两套 Telegram 界面。个人私聊语言与各群提示语言独立保存，重启后保留；切换语言不会改变防护、积分或词库设置。

## 切换自己的语言

1. 私聊机器人发送 `/language`，或在 `/start` 群组选择页点击 **🌐 界面语言 / Language**。
2. 点击 **简体中文** 或 **English**，立即保存并刷新当前页面。
3. 没有群管理权限的普通成员也能切换自己的语言。

首次私聊时，Telegram 提供的语言代码为英语会自动使用 English；其他语言或未提供语言代码时默认中文。手动选择后以保存的选择为准，不会被客户端语言覆盖。

## 切换群内提示语言

管理员私聊机器人：**`/start` → 选择群 → 🌐 群内提示语言 → 选择语言**。

每次修改都会重新检查当前管理员身份。此设置只影响选中的群，不改变其他群或任何成员的个人语言。

| 内容 | 使用的语言 |
| --- | --- |
| 私聊管理页面、按钮、表单、确认与错误提示 | 操作者的个人语言 |
| 成员私聊服务：签到、积分、商城、订单、抽奖、群规 | 成员的个人语言 |
| 群内系统提示、验证、处罚提醒及命令回复 | 当前群的语言 |
| 未修改过的默认欢迎语、默认群规 | 发送目的地的语言 |
| 管理员自定义欢迎语、群规、公告、自动回复、奖励和活动名称 | 原文 |
| 群名、成员昵称、关键词、例外文本和导出词库 | 原文 |

即使自定义内容恰好与系统中文提示相同，管理员重新保存后也会保留原文。升级前内容与旧版默认欢迎语、群规完全相同且没有自定义标记时，视为默认内容；其他已有内容保留原文。

## 命令菜单与使用范围

机器人启动时注册中英文 `/` 命令说明；手动切换后也会更新对应私聊或群的命令菜单。Telegram 客户端可能缓存菜单，重新打开输入框后查看。命令名称如 `/rules`、`/checkin` 保持一致。

群内发送 `/language` 可获得私聊入口；普通成员不能借此修改群语言。服务器 `gg` 菜单和本使用文档仍为中文，本功能不是语音识别或自动翻译群聊。

## 更新后启用

在服务器运行 `gg update`，机器人重启后即可看到语言入口。个人或群设置中暂时没有入口时，先确认服务器源码已更新，再重新发送 `/start`。

开发者可在 `app/locales/` 维护翻译；`python scripts/prepare-i18n.py --check` 会检查源文案覆盖与格式占位符。运行时本地加载文案，不调用翻译服务，也无需新增 Python 依赖。
