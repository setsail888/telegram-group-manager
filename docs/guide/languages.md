# 界面语言切换

机器人提供 **26种 Telegram 界面语言**。控制面板里的 **🌐 语言 / Language** 切换你自己的整套私聊界面，选中后立即刷新面板。个人语言与各群提示语言独立保存，重启后保留；切换不改变防护、积分或词库设置。

| 设置 | 切换后的作用 |
| --- | --- |
| 个人界面语言 | 改变本人私聊管理页、成员服务、按钮和系统提示；不改变其他人的界面 |
| 群内提示语言 | 改变选中群的机器人系统提示、验证和命令回复；需要该群管理员权限 |
| 管理员自定义内容 | 欢迎语、群规、公告和自动回复仍用保存的原文；需要英文内容时自行编辑 |

例如你把个人语言切为English、群语言仍为中文：你的私聊按钮用英文，群里新人验证仍用中文。把群语言改为English后，其他成员各自的私聊语言也不会被改动。

## 切换自己的语言

1. 私聊机器人 `/start` → 选择群 → 底部 **🌐 语言 / Language**。
2. 在两列语言列表中选择，例如 **🇺🇸 English**；选中项带✅标记。
3. 立即保存并返回同一个群的控制面板，标题、按钮、子页、说明和表单改用所选语言。

也可私聊发送 `/language`，或在群组选择页、成员服务点击 **界面语言 / Language**。这些入口不要求管理员身份，选择后刷新语言页；普通成员只能修改自己的私聊语言。

首次私聊时，Telegram提供的语言代码在支持范围内会自动选用对应语言，例如 `fr-FR` 使用法语、`pt-BR` 使用葡萄牙语；未提供或暂不支持时默认中文。手动选择后以保存的选择为准。

## 切换群内提示语言

管理员私聊机器人：**`/start` → 选择群 → 🌐 语言 / Language → 💬 单独设置群内提示语言 → 选择语言**。

每次修改都会重新检查当前管理员身份。此设置只影响选中的群，不改变其他群或任何成员的个人语言。

| 内容 | 使用的语言 |
| --- | --- |
| 私聊管理页面、按钮、表单、确认与错误提示 | 操作者的个人语言 |
| 成员私聊服务：签到、积分、商城、订单、抽奖、群规 | 成员的个人语言 |
| 群内系统提示、验证、处罚提醒及命令回复 | 当前群的语言 |
| 未修改过的默认欢迎语、默认群规 | 发送目的地的语言 |
| 管理员自定义欢迎语、群规、公告、自动回复、奖励和活动名称 | 原文 |
| 群名、成员昵称、关键词、例外文本和导出词库 | 原文 |

即使自定义内容恰好与系统中文提示相同，管理员重新保存后也会保留原文。升级前内容与旧版默认欢迎语、群规完全相同且没有自定义标记时，视为默认内容；其他已有内容保留原文。

## 命令菜单与使用范围

机器人启动时注册默认中英文 `/` 命令说明；手动切换后更新对应私聊或群的命令菜单为所选语言。Telegram客户端可能缓存菜单，重新打开输入框后查看。命令名称如 `/rules`、`/checkin` 保持一致。

群内发送 `/language` 可获得私聊入口；普通成员不能借此修改群语言。服务器 `gg` 菜单和本使用文档仍为中文，本功能不是语音识别或自动翻译群聊。

## 更新后启用

在服务器运行 `gg update`，机器人重启后即可看到语言入口。个人或群设置中暂时没有入口时，先确认服务器源码已更新，再重新发送 `/start`。

开发者可在 `app/locales/` 维护翻译；`python scripts/prepare-i18n.py --check` 检查所有可选语言的源文案覆盖与格式占位符。新增文案需同步每个语言包。
