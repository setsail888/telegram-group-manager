# 权限与按钮操作

## 管理员从哪里进入

私聊机器人发送 `/start` → 选择群组 → 点击对应功能。群内 `/panel` 也可打开管理入口。每个按钮会重新检查真实管理员身份，各群设置独立。

## 机器人需要哪些权限

| 功能 | 所需条件 |
| --- | --- |
| 删除广告、链接、刷屏消息 | 机器人为群管理员，并有删除消息权限 |
| 禁言、封禁、新人验证、集中入群保护 | 超级群，并有删除消息、限制成员等对应权限 |
| 欢迎语、自动回复、公告 | 机器人能够在群内发送相应文字或媒体 |
| 日志群 | 管理员本人和机器人都具备目标群相应身份，机器人可发送日志 |

在管理菜单打开 **权限检查**，或群内发送 `/check` 查看当前状态。权限查询失败时先重试；不要据此认定已经授权成功。

“权限检查”只查看状态，不会自动替机器人提升权限。需要到Telegram群管理界面授予权限；开关已开启也不代表机器人一定具备执行条件。

## 设置怎么保存

开关和数值按钮按页面提示修改。需要输入内容的功能一般采用：**点击功能 → 分步发送内容 → 操作预览 → 确认执行**。

预览的“十分钟内有效”只表示这次确认请求的有效期。确认后设置保存在数据库，重启后仍保留。并非功能只运行十分钟；已有禁言/封禁本身的时长另行计算。

过期、重复确认、其他管理员已修改同一配置、机器人重启或权限变化时，需要重新预览。发送 `/cancel` 或返回其他管理页面可取消未完成草稿。部分旧版违禁词编辑入口为即时保存，以机器人返回结果为准。

| 页面上的时间 | 实际限制什么 |
| --- | --- |
| 操作预览“十分钟内有效” | 本次确认按钮的有效期；确认后的设置持续保存 |
| 转赠或兑换“五分钟内有效” | 本次扣分确认的有效期；未确认不扣分，已完成记录不会五分钟后消失 |
| 禁言30分钟 / 封禁1天 | 已执行成员处罚的持续时间 |
| 刷屏窗口60秒 | 统计最近60秒的消息，不是功能60秒后关闭 |
| 集中入群保护10分钟 | 对后续新人的额外验证要求持续多久，不是每人的答题时限 |

## 观察模式的范围

**智能反垃圾 → 仅观察内容过滤** 会把违禁词、链接、转发、刷屏、图片与频道过滤切为只记录。它优先于分类和跨账号功能的处罚设置。

新人验证、昵称限制、其他机器人清退以及管理员手动管理仍各自生效。观察模式不能用来暂停所有群管理功能。

## 查看群 ID 和成员 ID

- 管理员在群内发送 `/id`，查看群 ID。
- 管理员回复目标成员消息发送 `/id`，查看目标 ID。
- 成员私聊机器人 `/id`，查看自己的数字 ID。

手动成员管理要求数字 ID，不是 `@用户名`。选择正确群组，再检查操作预览中的目标。

## 找不到按钮或点不动

先执行 `gg update` 更新程序，重新发送 `/start` 获取新菜单。若旧确认已失效，重新打开功能。延迟问题见[管理按钮排查](../slow-buttons.md)，未显示群组见[常见问题](faq.md)。
