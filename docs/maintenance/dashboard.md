# 只读网页看板

看板可查看群统计、积分、订单、任务和抽奖，不能编辑群规则、禁言或封禁成员。它是你自己服务器上的管理看板，与当前公开文档站是两个不同入口。

## 启动看板

在服务器SSH中执行：

```bash
gg dashboard
```

选择1。首次会生成独立随机密钥，仅显示一次，请保存。它不是BotFather Token。

## 用SSH隧道访问

看板只绑定服务器 `127.0.0.1:8765`。在本地Windows PowerShell执行：

```powershell
ssh -N -L 8765:127.0.0.1:8765 ubuntu@你的服务器IP
```

将用户名与IP换成实际服务器值，保持窗口开启。在本地浏览器打开 `http://127.0.0.1:8765`，输入看板独立密钥。

不必在防火墙额外开放8765端口。此处本地回环地址通过SSH隧道使用，不是让你把未加密看板直接公开。

## 停止与排查

再次运行 `gg dashboard` 选择2停止。无法访问时检查隧道是否仍连接、端口是否被本地程序占用，以及看板容器状态。

公开使用教程无需该密钥；本页面不会连接或读取你的服务器数据。
