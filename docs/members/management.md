# 昵称、机器人与手动管理

| 功能 | 开启或操作后的作用 |
| --- | --- |
| 超长昵称限制 | 新人入群时，昵称长度超过设置值，临时限制发言30分钟；不持续检查所有成员改名 |
| 拦截新人机器人 | 清退新加入的其他机器人；不会扫描并移除原有机器人 |
| 警告 / 清除警告 | 增加或清除该成员在本群的警告次数；达到上限后尝试禁言 |
| 禁言 / 解禁 | 限制发言，或解除成员发言限制；解禁不是让被封禁的人重新入群 |
| 移出 | 将成员踢出，允许重新加入 |
| 封禁 / 解封 | 阻止成员重新加入，或解除入群封禁；解封不自动把人拉回群里 |

昵称限制、机器人防护和手动管理相互独立；内容过滤的“仅观察”不会暂停这三项。只开昵称限制不会检测昵称里的诈骗词，也不会自动清理消息广告。

## 超长昵称限制

**入口：新成员限制 → 超长昵称限制。** 默认关闭，初始允许昵称最大长度40，可调20–100。用于入群阶段的昵称检查，不是关键词昵称黑名单。

需要超级群及限制成员权限。先用正常长昵称、表情昵称在测试群验证，再根据实际情况开启。该限制不受内容过滤观察模式控制。

入群时昵称过长会限制发言30分钟；若新人本次需要常规或集中入群验证，优先走验证流程，不叠加这项昵称限制。

初始上限40表示超过40才触发：40个字符不超限，41个才超限。按昵称文本长度计算，复杂表情可能占多个字符，不等于屏幕显示的字块数。

## 其他机器人入群

**入口：机器人防护 → 拦截新人机器人。** 默认关闭，开启后检查新加入的其他机器人并清退，不能替代对已经在群内机器人的人工检查。

群内命令：`/bots on`、`/bots off`。需要超级群和对应管理权限；本机器人受保护。

## 手动管理成员

**入口：成员管理 → 选择操作 → 输入数字用户ID → 预览确认。** 可以警告、清除警告、禁言、解禁、移出、封禁或解封。

1. 在目标群回复成员消息发送 `/id` 获取数字 ID，或让成员私聊机器人 `/id`。
2. 在该群的私聊管理页选择操作并输入 ID。
3. 禁言时输入分钟数，手动禁言表单支持1–1440分钟。
4. 核对群组、目标和操作，确认执行。

管理员和本机器人受保护，执行前重新核验身份和权限。不能把 `@用户名` 当作数字 ID。

## 群内回复命令

管理员回复目标成员消息后发送：

```text
/warn
/unwarn
/mute 60
/unmute
/kick
/ban
```

解封可使用 `/unban 数字用户ID`。`/dban` 会删除被回复消息并封禁。封禁可能撤销超级群内该成员的其他历史消息，详见[处罚范围](../moderation/penalties.md#封禁的历史消息范围)。

当前手动“移出”及 `/kick` 采用先封禁、再解封的流程，在超级群中也可能撤销该成员历史消息；若解封失败，需手动解除封禁才能重进。防刷屏的“踢出”使用不同处理流程，不能把它的历史消息范围套用到手动移出。只需限制发言时可选择禁言。

手动警告默认达到3次后尝试禁言60分钟，警告上限可调；防刷屏警告共用计数，但达到上限时使用防刷屏自己的禁言时长。

手动操作不会因为全局内容观察而暂停。处罚记录可查看[管理日志](../operations/statistics.md#独立管理日志群)。
