# 集中入群防护

**入口：集中入群防护。** 当短时间大量不同账号入群时，暂时对触发者和之后的新人要求答题，不追溯此前成员。需要超级群和限制成员权限，自动检测默认关闭。

## 各功能有什么用

| 功能 | 开启或操作后的作用 |
| --- | --- |
| 自动检测 | 按入群人数和窗口触发临时保护；不开时仍可手动开始 |
| 触发入群人数 / 入群窗口 | 统计窗口内不同普通成员；初始60秒内达到10人时触发 |
| 保护时长 | 决定接下来多久对新加入者额外要求答题，初始10分钟；不是每人的答题时间 |
| 立即开始保护 | 无需等待人数达标，确认后开始临时保护 |
| 停止额外保护 | 停止对后续新人的额外要求；已发出的验证题仍需完成 |

按初始值，第10个符合条件的新人入群时触发，他和保护期间后来加入的新人需要验证；前9人不会被追溯验证。每个人仍使用新人验证页的300秒时限和3次答错上限，已有群以实际配置为准。

## 设置自动保护

1. 进入集中入群防护，开启自动检测。
2. 调整入群人数、检测窗口和保护时长。
3. 检查新人验证页的题目时限与答错次数，它们也用于此处。
4. 在测试群检查触发、答题和保护结束。

| 参数 | 新群初始值 | 可调范围 |
| --- | --- | --- |
| 不同普通成员人数 | 10人 | 3–100人 |
| 入群窗口 | 60秒 | 10–300秒 |
| 保护时长 | 10分钟 | 1–60分钟 |

管理员、机器人和已有个人限制的成员不计入触发人数；无法可靠核验身份时跳过。重复入群事件不会增加同一人的计数。

只开集中入群防护、常规新人验证关闭时，平时入群不要求答题；人数触发或手动保护期间才要求。若希望每个新人都验证，应另开[新人验证](verification.md)。

## 手动开始或停止

点击 **立即开始保护**，查看预览并确认。当前状态会显示保护截止时间。点击 **停止额外保护**，确认后停止对后续新人的额外要求。

关闭自动检测只影响今后触发，不会提前取消已有保护。保护到期或手动停止后，已经收到验证题的成员仍需完成验证或等待超时清理。

## 重启后的状态

保护截止时间保存在数据库，重启后保留；窗口内入群人数为内存计数，重启后重新累计。常规新人验证若开启，保护结束后仍按常规规则执行。

参数不是适用于所有群的固定标准。活动或直播拉新期间，正常入群也可能集中，按本群规模调整。
