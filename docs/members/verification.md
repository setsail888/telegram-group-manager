# 新人验证

**入口：新人验证。** 新成员入群后完成题目，验证前限制发言。需要超级群和机器人限制成员权限，默认关闭。

## 各设置有什么用

| 功能 | 开启或调整后的作用 |
| --- | --- |
| 新人验证开关 | 对新加入的普通成员要求答题；不会重新验证已经在群里的所有成员 |
| 验证时限 | 从本次验证开始计算，限定答题时间；初始300秒，即5分钟 |
| 最多答错次数 | 限定同一题允许的错误次数；用完后保持受限，等待超时处理 |
| 答对 | 通过本次验证并解除本次验证限制 |
| 验证超时 | 移出该成员，允许重新加入；不永久封禁 |

例如时限300秒、最多答错3次：答错第1、2次还可再试，第3次后不能继续猜；不会立即永久封禁，仍按本次验证截止时间处理。

## 开启步骤

1. 先到权限检查确认群类型和限制成员权限。
2. 打开新人验证，开启开关。
3. 设置验证时限和最多答错次数。
4. 用普通测试账号加入群，检查题目、答对解限和超时处理。

| 参数 | 新群初始值 | 可调范围 |
| --- | --- | --- |
| 验证时限 | 300秒 | 60–1800秒 |
| 最多答错 | 3次 | 1–5次 |

群内也可发送 `/captcha on` 开启，或 `/captcha off` 关闭。

只开新人验证即可对新加入的普通成员要求答题，不必同时开启智能反垃圾或集中入群防护；已验证成员后续发广告，仍需关键词、链接等内容规则检查。

## 答错或超时会怎样

答错次数用完后保持受限，不再无限尝试。验证超时后移出成员，允许重新加入；不是永久封禁。题目只允许对应新人作答，其他人不能代答。

重复入群事件不会重置同一待验证任务或答错次数。已存在个人限制的成员不会被新验证题随意覆盖。

## 与欢迎语、观察模式的关系

验证题独立发送，不占欢迎语的每分钟额度。即使欢迎消息被限频，也应能收到验证题。

内容过滤“仅观察”不暂停新人验证。常规新人验证和[集中入群保护](raid.md)相互独立；关闭集中入群自动检测不代表关闭常规验证。

## 新人看不到题目

检查机器人发送消息和限制成员权限、群类型及网络；查看 `gg logs`。不要在无法确认题目已正常发送时，直接把验证时限调得很短。

待验证成员不能使用签到、兑换、抽奖等成员服务；完成验证后再进入[成员菜单](../community/menu.md)。
