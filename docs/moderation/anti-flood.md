# 个人防刷屏与图片

**按钮入口：防刷屏、图片防刷。** 个人规则按账号分别计数；多人发送相同广告请另看[跨账号重复检测](../cross-account-flood.md)。

## 开启步骤

1. 打开防刷屏，检查主开关。新群默认开启。
2. 设置短时消息条数、窗口和重复消息规则。
3. 按群习惯决定是否启用媒体连发、相册按一条计数。
4. 打开 **惩罚**，选择仅撤回、警告、禁言、踢出或封禁，预览后确认。
5. 先在测试群以普通账号检查效果，通过防护记录调节阈值。

## 个人规则参数

| 参数 | 新群初始值 | 可调范围 |
| --- | --- | --- |
| 短时消息条数 | 7条 | 3–30条 |
| 刷屏窗口 | 10秒 | 3–120秒 |
| 相同文字次数 | 3次 | 2–10次 |
| 重复判断窗口 | 45秒 | 10–300秒 |
| 媒体连发 | 关闭；5条/20秒 | 2–30条，5–120秒 |

个人短时消息和媒体连发在超过所设条数时触发；相同文字和重复图片达到所设次数时触发。编辑不增加次数，同消息重投在窗口内去重。具体命中原因以防护记录为准。

文字重复使用完整内容摘要，不只比较开头；不同文字不会仅因前缀一样被合并。独立的关键词、链接规则仍会检查每条内容。

## 图片与相册

**图片防刷 → 重复图片拦截** 默认关闭，初始3次/60秒，可调2–10次、30–600秒。它检查同账号重复图片；与所有媒体的发送频率规则不同。

**防刷屏 → 媒体连发 → 相册按一条计数** 默认关闭。开启后，同一相册对条数和媒体次数按一组计算，但每张图片说明仍参与关键词检查，文本重复规则仍生效。

图片没有文字说明时，仍可参与图片/媒体检测；需要识别图片里的文字，另行部署[OCR](ocr.md)。

## 怎么减少误报

聊天活跃或经常发相册的群，可适当增加窗口内允许条数，或使用相册合并计数。不要直接使用很低的阈值处罚正常讨论。

全局观察开启时只记录内容过滤命中；选择仅撤回时仍会删除触发消息，但不追加成员处罚。两者区别见[惩罚说明](penalties.md)。

## 会回删之前的正常消息吗

个人刷屏默认删除触发消息，不回溯删除正常消息。跨账号检测可清理缓存的同内容消息；封禁则受Telegram超级群历史撤销行为影响，选择前请看[封禁范围](penalties.md#封禁的历史消息范围)。
