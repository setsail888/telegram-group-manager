# 智能反垃圾与链接

**按钮入口：智能反垃圾、链接管理、域名白名单。** 本功能使用本地规则，不调用大模型进行语义判断。

## 开启与测试

1. 打开智能反垃圾，先开启 **仅观察内容过滤**。
2. 开启智能反垃圾；需要检查网址时，同时开启链接拦截。按本群讨论方式调整批量提及次数。
3. 点击 **测试文字规则**，发送广告和正常文字，检查命中原因。
4. 查看防护记录，补充必要的白名单或关键词例外。
5. 确认合适后关闭全局观察，恢复实际处罚。

测试只检查文字规则，不模拟刷屏次数或执行成员处罚。

## 能检查什么

| 功能 | 开启后的作用 |
| --- | --- |
| 智能反垃圾 | 检查正文、图片说明中的批量显式 `@账号` 和隐藏提及；同时开启“链接拦截”后，进一步检测 `t[.]me`、`hxxps://` 等部分伪装网址 |
| 链接拦截 | 拦截普通网址、文字背后的隐藏链接、按钮链接；域名白名单中的链接放行 |
| 禁止转发 | 拦截带Telegram转发来源的消息；复制粘贴、截图重发不属于这种转发 |
| 拆字识别 | 增强已有包含规则，例如将 `刷·单·返·佣` 与 `刷单返佣` 匹配；两字拆分、拼音和同音增强另见[中文变体](variants.md) |
| 自动禁言 | 同一成员在10分钟内累计达到设定的实际删帖次数后，尝试禁言；默认关闭 |
| 仅观察内容过滤 | 只记录内容过滤命中，不删消息、不执行对应自动处罚；关闭后正常处理 |
| 拦截外部频道发言 | 拦截用户以外部频道身份发送的消息；保留本群匿名管理员和关联频道自动转发 |

“链接管理”与本页的链接拦截是同一个设置；“禁止转发”以及违禁词页的“拆字违禁词”也分别与这里共用开关。修改一处，另一处会同步显示。

新群默认链接拦截开启，智能反垃圾增强关闭。它使用规则识别，不会理解所有广告的语义。

它不会自动展开所有短链接，也不会判断每个落地网站是否安全；正常推广、新闻引用也需要本群规则配合。

## 参数怎么理解

| 参数 | 新群初始值 | 实际含义 |
| --- | --- | --- |
| 批量提及次数 | 5，可调3–20 | 一条消息中**超过5次，即第6次提及开始触发**；重复提及同一账号也计次数，不要求6个不同账号 |
| 连续违规次数 | 3，可调2–10 | 实际按同一成员**最近10分钟内累计成功删除的不同消息**计数；中间正常聊天不会清零 |
| 自动禁言分钟 | 30，可调1–1440 | 达到累计门槛后的禁言时长；不开自动禁言时，这个数值不执行 |

例如成员先后被成功删帖3次，自动禁言开启且权限足够时，尝试禁言30分钟。只观察到3次、删除失败，或编辑同一消息，不会按3次累计。

## 只开启智能反垃圾，其他都关闭，能做什么

假设本页其他开关关闭，且违禁词、防刷屏、图片防刷和OCR等独立模块也关闭：

| 消息 | 是否由智能反垃圾处理 |
| --- | --- |
| 一条消息含6次显式或隐藏提及，阈值为5 | 会，按批量提及规则删除；自动禁言关闭时不因此禁言 |
| 一条消息只含5次提及 | 不会因批量提及触发 |
| 普通网址、`t[.]me` 等伪装网址 | 不会；需要另外开启链接拦截 |
| 带转发来源的普通文字 | 不会；需要另外开启禁止转发 |
| 只有推广文案，没有超量提及 | 不会仅凭“像广告”拦截；需要配置关键词等对应规则 |

只关闭本页其他开关，不会关闭独立页面里的违禁词、防刷屏、图片防刷或OCR。检查[规则总览](../operations/statistics.md)，才能确认当前群完整配置。

## 域名白名单

1. 打开 **域名白名单**，选择添加。
2. 发送域名，例如 `example.com`；多条每行一个，一批最多80个。
3. 检查预览并确认；删除时选择列表条目，再确认。

精确域名及其子域名会放行，例如 `example.com` 和 `help.example.com`；`evil-example.com` 不会因后缀相似被放行。白名单用于链接检查，不豁免独立的违禁词、刷屏或其他违规。

管理员也可在群内使用：

```text
/allowdomain example.com
/domains
/deldomain example.com
```

## 转发和频道身份

**禁止转发** 页面提供独立开关，默认关闭。开启后按转发规则检查，不代表全部链接同时被禁止。

**智能反垃圾 → 拦截外部频道发言** 默认关闭。开启后拦截外部频道身份发言；本群匿名管理员和关联频道自动转发保留。频道代发身份不会按普通成员执行禁言。

## 累计违规禁言

自动禁言可为链接、转发、批量提及、重复图片等实际删帖追加累计处理，并不要求智能反垃圾主开关开启。仅超级群支持，需要限制成员权限；频道代发身份不按普通成员执行禁言。

防刷屏明确选择警告、禁言等处罚时，不再叠加全局累计；选择新版“仅撤回消息，不处罚”也不计该次刷屏。旧设置兼容区别见[惩罚说明](penalties.md)。

## 命中却没有删帖

检查全局观察、管理员豁免、机器人删除消息权限，以及目标规则是否开启。查看[防护记录](../operations/statistics.md#防护记录)，区分观察、删除失败和成员处罚失败。
