# 导入、导出与精确例外

## 文件导入

**入口：违禁词 → 文件导入。** 发送 UTF-8 文件或粘贴文字，查看预览后确认。单文件最多1 MiB，可分批追加；词库总条数没有固定上限，仍需足够服务器资源。

### 每行一词

```text
# 注释和空行会忽略
刷单返佣
冒充官方客服
```

默认按包含匹配。每个词规范化后需2–80字；不支持正则表达式，`.*` 等内容按字面处理。

### JSONL 保留匹配方式

```json
{"word":"contact","mode":"word","label":"英文联系词"}
{"word":"联系客服","mode":"exact"}
{"word":"刷单返佣","mode":"contains"}
```

每行一个对象，不能把多条对象放到同一行。也支持“匹配方式 + Tab制表符 + 词条”，见[格式参考](../word-library.md#文件导入与导出)。

### 确认前检查

预览会显示新增、保留、重复数量以及样例。已有规则保留原标签和匹配方式，不会被导入文件覆盖。错误行或冲突会拒绝整批，避免保存一半；修改文件后重新导入。

若其他管理员改了词库，旧预览会失效，需要重试。导入不会替你开启过滤总开关或改变处罚。

## 导出自定义词库

点击 **导出自定义词库**，机器人在私聊发送 JSONL，保留词条、标签和匹配方式。较大词库分段导出，点击下一部分直到完成。

导出不包含内置分类开关、排除词或精确例外。完整群配置需要[数据库备份](../maintenance/server.md#更新与备份)，不能只保存词库文件。

## 精确例外怎么用

需要允许某句包含违禁词的正常文本时，在违禁词页面选择例外入口，按提示填写词与完整允许文本。也可在群内发送：

```text
/wordexcept 刷单 | 警惕刷单骗局
/wordtest 警惕刷单骗局
```

这只放行“刷单”这条规则对完整文本“警惕刷单骗局”的命中。若增加其他广告文字，或还有其他违禁词、链接违规，仍会检查。

启用中文变体后，例外仍填写原始关键词和实际发送的完整文字，例如 `刷单返佣 | 警惕唰单返佣`。移除例外可使用页面入口或 `/delwordexcept` 对应命令，完整命令见[速查](../commands.md)。
