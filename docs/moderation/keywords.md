# 违禁词与匹配方式

**按钮入口：私聊 `/start` → 选择群组 → 违禁词。** 用于检查正文、图片说明和可见按钮文字。管理员豁免自动内容过滤。

## 各功能有什么用

| 功能 | 开启或操作后的作用 |
| --- | --- |
| 违禁词总开关 | 决定本群是否执行关键词检查，包括已配置的分类和变体；关闭后保留词条及配置 |
| 添加自定义词 | 增加本群自己的规则；不自动启用全部内置词库 |
| 分类词库 | 按广告类型启用项目自带词条，各分类可关闭、观察或处罚 |
| 拆字违禁词 / 中文变体识别 | 扩展已有包含规则的写法；不会在没有基础词时自动判断广告 |
| 测试关键词 | 显示文字命中及原因，不删帖、不禁言，也不累计刷屏次数 |
| 精确例外 | 放行某一条关键词规则对指定完整文本的命中，不豁免其他规则 |
| 处罚与删除提醒 | 设置关键词删帖后是否追加禁言，以及是否发送临时提醒；不控制防刷屏处罚 |

只开启总开关，没有自定义词，也没有启用分类时，不会凭空产生关键词命中。已有自定义词则可独立工作，不要求开启智能反垃圾。

## 添加一条规则

1. 打开违禁词页面，确认违禁词总开关已开启。
2. 选择添加入口，发送要拦截的词，例如 `刷单返佣`，按提示保存。
3. 打开查看词库或搜索词库，选择该词，设置匹配方式，预览后确认。
4. 使用测试文字入口发送样例，查看命中词和原因。测试不删除消息、不产生处罚。

也可在群内发送管理员命令：

```text
/addword 刷单返佣
/wordtest 有人邀请我参加刷单返佣
/words
```

词条规范化后为2–80字。批量输入和文件格式见[导入导出](import-export.md)。

## 包含、整词、整句有什么区别

| 模式 | 含义 | 示例 |
| --- | --- | --- |
| 包含 | 消息中出现该词即命中 | `刷单` 会命中 `警惕刷单骗局` |
| 整词 | 两侧不能紧邻字母、数字、下划线或汉字 | `ad` 命中 `ad!`，不命中 `bad`、`汉ad字` |
| 整句 | 整段文字规范化后与规则相同 | `联系客服` 不命中 `请联系客服` |

默认使用包含匹配，并非只匹配完整句子。整词不做中文分词。三种模式均统一大小写、全半角及零宽字符；繁简、同音和拆字需按[中文变体说明](variants.md)单独配置。

## 测试和调优

先收集正常聊天和广告各几条样例，通过文字测试查看结果。需要验证真实自动删除时，在测试群使用普通成员账号发送消息；管理员账号不会触发实际自动过滤。

| 发现的问题 | 调整方法 |
| --- | --- |
| 合法引用被包含模式命中 | 改为整句、添加完整文本例外，或删除过宽泛的词 |
| 启用分类后某个词不合适 | 在分类里排除该词；同名自定义规则需单独处理 |
| 使用同音、繁体或拆字逃过规则 | 开启对应变体的观察模式，测试后再处罚 |
| 测试命中，但群内不删除 | 检查全局观察、规则模式、管理员豁免和删除消息权限 |

## 处罚和提醒

违禁词页面可配置删除或删除并禁言、禁言时长和删除提醒。它使用自己的处罚设置，不跟随“防刷屏 → 惩罚”的五种选项。禁言需要超级群和限制成员权限。

默认违禁词禁言时长为10分钟，页面可调5–1440分钟；默认不发送额外删除提醒。以当前群页面显示为准，已有群升级不会重置。
