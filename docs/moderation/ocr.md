# 图片 OCR

**按钮入口：图片 OCR。** OCR检查图片中的部分文字，不识别二维码或广告意图，默认关闭。

## 1. 服务器启用引擎

在服务器 SSH 中运行：

```bash
gg ocr
```

选择1启用，安装器构建带Tesseract中文识别的镜像。普通版建议1 vCPU、512 MB可用内存；OCR版建议2 vCPU、2 GB内存，镜像构建还需空间。完整部署见[服务器教程](../server-one-click.md#七图片-ocr可选)。

## 2. 群内先审核

1. 配置[独立管理日志群](../operations/statistics.md#独立管理日志群)。
2. 添加要检测的关键词，或启用适合本群的分类。
3. 打开图片 OCR，选择 **仅审核**，调整最低可信度。
4. 使用真实广告图片和正常图片测试，检查防护记录与日志。
5. 确认识别适合本群后，才选择自动删除。

也可在群内使用：

```text
/ocr review
/ocrconfidence 80
/ocr off
```

初始最低可信度75，可调40–95。“仅审核”不会自动删除图片；全局观察开启时，自动删除仍受观察模式限制。

## 为什么图片没有被删除

- 服务器OCR引擎尚未启用，或群模式仍为关闭/仅审核。
- 图片没有识别出对应词，或未达到可信度。
- 命中词少于四字；两字词不会用于OCR自动删除。
- 图片大小、队列容量或识别质量导致跳过。
- 发送者是管理员，或有精确例外、全局观察等保护。

精确例外同样适用。图片被编辑后旧识别任务会失效，避免按旧内容删除新消息。

## 关闭和恢复轻量版

群内选择关闭或发送 `/ocr off`，只关闭本群处理。服务器运行 `gg ocr` 并选择2，可关闭引擎并重建轻量镜像。
