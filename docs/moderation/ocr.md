# 图片 OCR

**按钮入口：图片 OCR。** OCR检查图片中的部分文字，不识别二维码或广告意图，默认关闭。

## 各设置有什么用

| 设置 | 启用后的作用 |
| --- | --- |
| 服务器OCR引擎 | 提供本机图片文字识别能力；只安装引擎，不会自动开启各群扫描 |
| 群模式：关闭 | 本群不进行OCR处理，不影响图片说明、重复图片和媒体频率检测 |
| 群模式：仅审核 | 识别到符合条件的关键词后记录命中，可发到管理日志群，不自动删除 |
| 群模式：自动删除 | 符合关键词及可信度条件时删除图片；仍受违禁词总开关、分类/变体观察模式和全局观察约束 |
| 最低可信度 | 过滤识别不可靠的结果；初始75，识别值达到75才继续匹配，不是“有75%概率是广告” |

OCR自动删除不会追加“违禁词处罚”或“防刷屏惩罚”里的禁言、踢出、封禁，也不计入全局累计禁言。只有图片说明被普通文字规则命中时，才走对应的文字处理。

只打开本群OCR模式而未部署引擎，或未启用任何对应关键词，都不能自动识别并清理广告图片。目前扫描Telegram照片，不扫描以文件发送的图片或视频中的画面。

## 1. 服务器启用引擎

在服务器 SSH 中运行：

```bash
gg ocr
```

选择 **1 安装并启用**，等待带Tesseract中文识别的镜像构建完成、机器人重启。然后重新打开机器人里的图片OCR页面，确认引擎显示 **已安装并启用**，再选择群模式。安装引擎不会自动开启任何群的OCR。

普通版建议1 vCPU、512 MB可用内存；OCR版建议2 vCPU、2 GB内存，镜像构建还需空间。完整部署见[服务器教程](../server-one-click.md#七图片-ocr可选)。

## 2. 群内先审核

1. 按需配置[独立管理日志群](../operations/statistics.md#独立管理日志群)，也可只查看机器人里的防护记录。
2. 添加要检测的关键词，或启用适合本群的分类。
3. 打开图片 OCR，选择 **仅审核**，调整最低可信度。
4. 使用真实广告图片和正常图片测试，检查防护记录与日志。
5. 确认识别适合本群后，才选择自动删除。

也可在群内使用：

```text
/ocr review
/ocrconfidence 80
/ocr off
```

初始最低可信度75，可调40–95。“仅审核”不会自动删除图片；全局观察开启时，自动删除仍受观察模式限制。

## 点击确认后仍是off怎么办

`off`表示关闭，`review`表示仅审核，`delete`表示自动删除。按钮上的✅标记表示当前保存的模式；重复点击当前模式只提示“无需重复保存”。

切换时，预览会显示 **当前模式 → 目标模式**。例如 **关闭（off）→ 仅审核（review）**，确认后立即刷新OCR页面并标记新模式。如果预览的目标是off，确认执行的是关闭，不是启用。

引擎显示 **未启用/未安装** 时，群按钮无法安装服务器软件，点击启用模式会直接显示`gg ocr → 选择1`的步骤，不再生成无法执行的确认预览。先完成服务器安装，再重新选择群模式；若引擎仍不可用，检查服务器是否已完成镜像构建与容器重启。

自动删除还需要机器人具有删除消息权限。确认前后若模式已被其他管理员修改，旧预览会失效，需要重新选择，避免覆盖新的设置。

## 为什么图片没有被删除

- 服务器OCR引擎尚未启用，或群模式仍为关闭/仅审核。
- 图片没有识别出对应词，或未达到可信度。
- 命中词少于4个字符；短词不会用于OCR处理。
- 图片大小、队列容量或识别质量导致跳过。
- 发送者是管理员，或有精确例外、全局观察等保护。

精确例外同样适用。图片被编辑后旧识别任务会失效，避免按旧内容删除新消息。

## 关闭和恢复轻量版

群内选择关闭或发送 `/ocr off`，只关闭本群处理。服务器运行 `gg ocr` 并选择2，可关闭引擎并重建轻量镜像。
