# 警告、禁言与封禁

## 先分清处罚入口

| 入口 | 管理的处罚 |
| --- | --- |
| 违禁词 → 处罚 | 关键词命中后删除，或删除并禁言；不控制其他类型违规 |
| 防刷屏 → 惩罚 | 个人频率、重复文字、媒体连发和跨账号重复的成员处罚 |
| 智能反垃圾 → 自动禁言 | 对符合条件的实际删帖累计处理；具体刷屏处罚和已执行的关键词禁言不重复叠加 |
| 成员管理 | 管理员指定目标后手动执行，不要求先触发自动检测 |

只选择“禁言”或“封禁”不会启用对应检测。需要先开启防护规则，再设置命中后的处理方式；全局观察开启时，自动内容处罚仍只记录。

## 防刷屏惩罚

**入口：防刷屏 → 惩罚。** 适用于个人频率、重复文字、媒体连发及跨账号重复。选择方式，检查预览，再确认；违禁词使用自己的处罚设置。

| 方式 | 删除触发消息成功后 |
| --- | --- |
| 仅撤回消息，不处罚 | 不追加成员处罚，本次刷屏不计入全局累计禁言 |
| 警告 | 累加本群警告，达到上限后尝试禁言；成功才清零 |
| 禁言 | 按设定时长限制当前发送者 |
| 踢出 | 移出当前发送者，允许重新加入 |
| 踢出＋封禁 | 移出并阻止重进，到期或解封后才允许加入 |

警告、禁言、踢出、封禁需要超级群和对应管理权限。删除失败时不追加成员处罚；处罚失败会单独记录，不自动升级处罚。

## 设置时长

点击 **设置禁言时长** 或 **设置封禁时长**，选择预设，或输入自定义整数分钟数，预览后确认。

- 预设：10分钟、1小时、1天、7天、30天、365天。
- 自定义：1–525600分钟；封禁可输入0表示永久。
- 新群初始禁言10分钟、封禁1天，以当前页面显示为准。

更改只影响今后的处罚，不会重算已经生效的禁言/封禁期限。预览十分钟有效，确认后的设置持续保存。

## 跨账号清理处罚谁

例如A发2条、B发2条、C发第5条相同广告，满足账号数与条数门槛后：清理窗口内缓存的这5条同内容消息，但只对C执行所选成员处罚，A、B不追罚。用于降低复制正常成员消息反过来处罚原作者的风险。

持续同内容刷屏仍会拦截；管理员和机器人保护、缓存范围见[跨账号指南](../cross-account-flood.md)。

## 封禁的历史消息范围

Telegram在超级群封禁成员时会撤销其其他历史消息。界面选择封禁时会提示这点。

希望只撤回检测到的内容，可选仅撤回、警告、禁言或踢出。踢出允许重新加入，和封禁不是同一个效果。

这里的“踢出”指防刷屏惩罚选项。当前手动成员管理的移出及 `/kick` 先封禁再解封，历史消息范围不同，见[手动管理说明](../members/management.md#群内回复命令)。

## 全局累计与旧设置

旧版“单次仅删除触发消息”继续沿用已有全局累计违规禁言。新版“仅撤回消息，不处罚”明确让本次刷屏退出累计；其他明确刷屏处罚也不重复叠加全局累计。

与刷屏独立的违禁词、链接违规仍可按其规则处理。警告次数与管理员手动警告共用，默认上限3次，可调1–10。

例如此前没有警告记录，上限为3，防刷屏选“警告”：前两次分别累计到1、2次，第3次尝试按防刷屏禁言时长禁言；成功后清零，失败则保留次数。中途管理员手动警告，也会计入同一份本群记录。

手动处理某个成员见[成员管理](../members/management.md#手动管理成员)。
