# 两字词、繁简与同音

**按钮入口：违禁词 → 中文变体识别。** 用于增强已启用的包含规则，不会自动添加或启用所有词。

## 先准备基础词

添加自定义包含词，例如 `刷单`，或启用包含该词的分类。需要短词时，打开 **分类词库 → 两字短词（严格）**，先选仅观察。

基础词没有启用时，只打开变体功能也不会凭空命中。

## 三项功能分别做什么

| 功能 | 可识别示例 | 范围 |
| --- | --- | --- |
| 繁简字形 | `刷單` 对应 `刷单` | 固定字符映射，不是完整词组翻译 |
| 定向同音/拼音 | `唰单`、`shuadan` | 项目维护的指定别名，不覆盖任意同音字 |
| 短词拆字增强 | `刷⭐单` | 对相邻汉字间有限间隔的拆分进行识别 |

原有“拆字违禁词”开关继续可用；新增短词增强用于补充两字等短规则。变体只扩展包含模式，整词和整句保留原有精度。

## 开启步骤

1. 打开中文变体识别，点击 **三项全部先观察**，预览并确认；也可逐项设置。
2. 通过文字测试检查原写法、变体写法与本群正常话题。
3. 在防护记录里查看命中词和识别类型。
4. 将需要执行的项目切为执行处罚。基础分类若仍仅观察，组合命中依然只观察。

三项默认关闭。繁简与同音可以组合，但只在同一正文、说明或按钮内部处理，不跨按钮、换行任意拼接。

## 为什么有些同音写法没命中

定向别名清单不是通用拼音模糊匹配。某些易混词还要求同分句附近有提示语，例如“菠菜”需要附近的博彩上下文，减少正常饮食讨论误报。

实际发现漏判时，先保留广告样例以及对应的正常聊天反例，再决定添加规则或改进别名；不要直接把所有同音词都设为禁止。

## 误报怎么处理

可以排除内置词、改为整句匹配，或设置 **原关键词 + 完整允许文本** 的[精确例外](import-export.md#精确例外怎么用)。额外广告文字、其他词条或其他违规不会一起被放行。

OCR仍要求达到可信度且命中词至少四字；两字词开启变体后也不会因此进入图片自动删除。详细技术范围见[词库完整说明](../word-library.md#两字词繁简与同音绕过)。
