# 两字词、繁简、同音与拼音混写

**按钮入口：违禁词 → 中文变体识别。** 用于增强已启用的包含规则，不会自动添加或启用所有词。

## 先准备基础词

添加自定义包含词，例如 `刷单`，或启用包含该词的分类。需要短词时，打开 **分类词库 → 两字短词（严格）**，先选仅观察。

基础词没有启用时，只打开变体功能也不会凭空命中。

## 六项功能分别做什么

| 功能 | 可识别示例 | 范围 |
| --- | --- | --- |
| 繁简字形 | `刷單` 对应 `刷单` | 固定字符映射，不是完整词组翻译 |
| 定向同音/拼音 | `唰单`、`shuadan` | 项目维护的指定别名，不覆盖任意同音字 |
| 短词拆字增强 | `刷⭐单` | 对相邻汉字间有限间隔的拆分进行识别 |
| 拼音＋中文混写 | `shua单返yong`、`地下银hang`、`chong庆贷款` | 完整拼音与中文混写，支持多音字读音，保留原汉字 |
| 拼音缩写（上下文） | `sdfy，日结加我`、`刷d返y，日结加我` | 缩写、完整拼音与中文组合；需要附近独立招揽提示 |
| 同音字增强（上下文） | `刷单返拥，日结加我` | 限定替换字数、原字锚点及上下文；与定向别名独立 |

原有“拆字违禁词”开关继续可用；新增短词增强用于补充两字等短规则。变体只扩展包含模式，整词和整句保留原有精度。

## 开启步骤

1. 打开中文变体识别，点击 **六项全部先观察**，预览并确认；也可逐项设置。
2. 通过文字测试检查原写法、变体写法与本群正常话题。
3. 在防护记录里查看命中词和识别类型。
4. 将需要执行的项目切为执行处罚。基础分类若仍仅观察，组合命中依然只观察。

六项默认关闭。可组合识别，例如开启繁简、拆字和混写后识别 `shua單⭐返yong`。只在同一正文、说明或按钮内部处理，不跨按钮、换行任意拼接。

## 拼音＋中文怎么启用

1. 先添加包含词，例如 `接码平台`，或开启包含该词的分类。
2. 在 **违禁词 → 中文变体识别 → 拼音＋中文混写** 选择 **仅观察**，确认保存。
3. 用 **测试关键词** 输入 `接ma平tai`、`jie码平台` 和本群正常聊天样例。
4. 查看防护记录后，按需要改为 **执行处罚**，预览并确认。

这项使用本地固定拼音表，不必为每种中文与拼音的组合手工加词。匹配范围仍有约束：

- 基础词至少含两个可识别汉字；命中的片段同时含中文和完整拼音，不识别任意纯拼音或首字母缩写。
- 支持大小写、全半角和带声调字母，例如 `shuǎ单返yōng`；`ü` 对应 `v`，数字声调如 `shua1` 暂不支持。
- 拼音片段可有不超过三个连续空格、连字符或撇号；不跨换行、句号、表情或可见按钮，不嵌入更长的英文标识符。
- 剩余汉字必须与原规则一致，混写模式不会把任意同音字当成原字。同音、繁简和拆字需分别开启。
- 支持6,986个多音字的去重读音，例如 `音yue` 对应 `音乐`、`地下yin行` 对应 `地下银行`；剩余汉字仍必须是原字，不会把“银杏”当“银行”。不靠展开所有读音组合生成海量词条。

包含匹配仍会命中反诈引用，例如 `警惕shua单返yong`；用原关键词和完整原文本设置精确例外。只开混写不会自动开启任何词库，也不会放宽整词或整句规则。

## 拼音缩写和同音增强怎么启用

1. 先启用基础包含词，如 `刷单返佣`。
2. 在同一菜单中分别设置 **拼音缩写（上下文）**、**同音字增强（上下文）**，先选仅观察并确认。
3. 测试 `sdfy，日结加我`、`刷d返y，日结加我`、`刷单返拥，日结加我`，再测试本群的聊天样例。
4. 查看防护记录，确认适合本群后切换执行处罚。两项升级后默认关闭，不自动改变原有群设置。

新增两项采用以下保守条件：

- **独立提示**：命中片段两侧各24字内、同一分句中，必须有“日结、加我、下单、出售、下注”等招揽提示。不能拿片段内部的词当提示，不跨正文、图片说明、按钮、换行或句号等边界。
- **缩写**：至少两个汉字的基础词；任意纯缩写至少对应四个汉字，并要求与相邻中英文字母、汉字、数字和下划线分开。两三字规则至少保留一个原汉字，且需要该词的专用提示。例如“刷d，日结加我”可命中；“sd，日结加我”不会泛化为“刷单”。缩写功能本身支持完整音节混用，例如 `sd返yong`，需要至少使用一次首字母；不因此开启任意纯全拼识别。
- **同音**：用词组优先读音，其他字用常用首音，不用任意生僻读音凑匹配。至少保留一半原汉字；四至七字最多替换一字，八字及以上最多替换两字。两三字必须属于有专用上下文的词条，并保留原字。例如“赌搏，充值加我”可以命中；“读博”“威信”“博采”等常见歧义保守放过。繁简等价字仍由繁简开关处理，不能借同音增强绕过繁简观察设置。
- **正常聊天**：避开反引号代码、URL、`@账号`、`/命令` 和常见技术缩写；附近出现“警惕、谨防、不要参与”等明确反诈提示时，保守跳过新增模糊匹配。保护规则和专用提示清单保存在可审查的 `app/wordlists/phonetic-contexts.json`。
- **图片**：新增缩写和同音增强不参与OCR自动删除，避免图片识别错误叠加模糊匹配。完整拼音混写仍需原有OCR可信度及四字门槛。

这些是本地规则，不能理解全部语义。例如同音写法没有招揽提示、替换太多字或纯短缩写时，可能漏判；广告伪装成反诈提醒也可能被保守跳过。正常聊天恰好满足全部条件时仍可能误判，应先观察并保留反例。

**原有包含规则、完整混写和定向别名保持原行为。** 上述反诈保护只针对新增缩写/同音增强；“警惕刷单返佣”仍会命中字面包含词，定向别名也不会因此放行。需要允许指定引用时设置精确例外。

## 误报怎么处理

可以排除内置词、改为整句匹配，或设置 **原关键词 + 完整允许文本** 的[精确例外](import-export.md#精确例外怎么用)。额外广告文字、其他词条或其他违规不会一起被放行。

OCR仍要求达到可信度且命中词至少四字；两字词开启变体后也不会因此进入图片自动删除。详细技术范围见[词库完整说明](../word-library.md#两字词繁简与同音绕过)。
