# 启用分类词库

**按钮入口：违禁词 → 分类词库。** 内置13类、6,566条去重词条，包含73个两字词。分类均默认关闭；更新程序不会自动启用。

## 开启步骤

1. 私聊机器人 `/start`，选择要管理的群。
2. 打开 **违禁词 → 分类词库**。
3. 选择与本群有关的分类，点击 **仅观察**，查看预览并确认。也可使用“定向分类全部先观察”开启前六类的观察。
4. 查看 **防护记录**，确认命中的词条、分类和正常聊天误报情况。
5. 在分类里排除不适合本群的词，再将需要拦截的分类切为 **执行处罚** 并确认。
6. 检查违禁词总开关，以及 **智能反垃圾 → 仅观察内容过滤**；全局观察开启时仍不会处罚。

确认后的分类设置持续保存。“十分钟内有效”仅限制确认请求，详见[按钮操作](../guide/permissions.md#设置怎么保存)。

## 每种模式的效果

| 模式 | 命中后 |
| --- | --- |
| 关闭 | 该分类不参与匹配 |
| 仅观察 | 记录词条和分类，不执行该分类的处罚 |
| 执行处罚 | 按本群违禁词处罚设置执行，仍受总开关和全局观察控制 |

同一消息若另有可执行的链接、刷屏或其他词条违规，仍可能被相应规则处罚。一个分类处于观察模式，不等于整条消息获豁免。

例如“虚假投资”设为执行处罚，但全局观察开启，命中后仍只记录；关闭全局观察后，才按违禁词自己的处罚执行。若只有“虚假投资”启用，其他12类保持关闭，其他分类不会跟着开启。

分类负责提供基础词，中文变体负责扩展写法：启用分类不会自动开启拼音或同音识别。需要这些增强时，另到[中文变体识别](variants.md)设置。

## 分类选择建议

| 分类 | 使用前需要注意 |
| --- | --- |
| 刷单返佣、虚假投资、博彩推广、色情引流、违禁交易、账号数据交易 | 含招揽短语，引用或反诈提醒也可能命中 |
| 推广引流与刷量 | 群运营、营销技术讨论容易误报 |
| 冒充客服与钓鱼、英文诈骗推广 | 安全科普引用同样需要测试 |
| 两字短词（严格） | 词短，误判风险更高，优先仅观察 |
| 三类开源扩展 | 含较宽泛的词，按群主题选择 |

各分类完整条数与来源见[词库来源](../word-library.md#分类与来源)。这些词不是其他机器人的私有词库，也没有实际群聊命中率排名。

## 排除或恢复某个内置词

进入分类 → 查看词条 → 点击目标词 → 排除并确认。也可从分类首页输入完整词条排除或恢复。

排除只影响当前群的内置词库。同名自定义词依然有效；需要改变精度时，可添加同名自定义规则并选择整词或整句，覆盖内置词的默认包含方式。

## 如何确认已经生效

使用文字测试发送含目标词的样例，再查看防护记录。分类页面显示“执行处罚”、违禁词总开关开启、全局观察关闭，且机器人具有删除消息权限，才具备实际删除条件。
