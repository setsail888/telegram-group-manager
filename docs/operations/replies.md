# 自动回复

**入口：自动回复。** 当成员消息匹配关键词时发送预设内容，可使用文字、图片、视频、动图、文件和HTTPS按钮。

## 各功能有什么用

| 功能 | 配置后的作用 |
| --- | --- |
| 触发关键词 | 普通成员文字正文中包含任意一个配置词，即可触发；例如“帮助,教程”可匹配“哪里有教程” |
| 文字回复 | 发送预设答案，适合群规、常见问题和操作指引 |
| 媒体回复 | 发送保存的图片、视频、动图或文件；不是根据问题自动生成内容 |
| HTTPS按钮 | 为回复附加跳转入口；点击打开目标页面，不是在机器人内执行管理操作 |
| 全群每分钟回复上限 | 限制所有规则合计触发数量；另有每人每条规则60秒冷却 |
| 替换 / 删除规则 | 修改回答，或停止对应规则；没有需要另开的自动回复总开关，保存规则后即可参与匹配 |

只设置自动回复即可回答相应关键词，不要求开启智能反垃圾或积分。消息若先被内容防护命中，就不继续触发回复；管理员消息、图片说明和以 `/` 开头的命令也不走这个普通文字触发流程。

## 通过按钮创建

1. 点击添加入口，发送触发关键词，多个词用逗号分隔，例如 `帮助,教程`。
2. 发送回复正文，或直接发送带说明的媒体。
3. 填写按钮，例如 `使用文档 - https://example.com/help`；多个按钮用 `&&` 分隔，不需要按钮时发送 `-`。
4. 检查预览并确认。

一条规则支持1–8个关键词，匹配其中一个即可；最多3个HTTPS按钮。按钮不能使用明文HTTP、脚本网址或包含账号密码的URL。

每个关键词2–50个字符，统一大小写、全半角和零宽字符；这里是包含匹配，不继承违禁词的整词、整句、拼音或同音增强。按钮表单中的文字回复最多1500字，媒体说明最多1000字。

## 群内命令示例

```text
/addreply 帮助,教程 | 请先查看使用文档 | 使用文档 - https://example.com/help
/replies
/delreply 帮助,教程
```

示例域名需换成你的实际链接。群内媒体回复：回复已有媒体消息后发送 `/addreply 关键词 | 文字说明`，机器人保存并复用Telegram文件ID。

## 替换和删除

进入规则列表选择条目，按页面分步替换或确认删除。群内删除命令需提供同一组关键词，顺序可以不同。不同群的规则独立保存。

## 为什么没有重复回复

每人每条规则约60秒冷却；另有全群每分钟上限，初始20条，可调1–60。多人触发达到总限频后会略过，防止自动回复放大刷屏。

例如A刚触发“教程”，30秒后再次触发同一条规则会略过；B可触发自己的第一次回复，但所有成员合计到20次后，窗口内的后续触发会略过，不排队补发。同一条消息匹配多条规则时，最多回复其中一条。

检查是否被内容防护先拦截、机器人是否能发送对应媒体、保存的文件ID是否仍有效。建议用普通成员账号在测试群验证实际触发。
