# 自动回复

**入口：自动回复。** 当成员消息匹配关键词时发送预设内容，可使用文字、图片、视频、动图、文件和HTTPS按钮。

## 通过按钮创建

1. 点击添加入口，发送触发关键词，多个词用逗号分隔，例如 `帮助,教程`。
2. 发送回复正文，或直接发送带说明的媒体。
3. 填写按钮，例如 `使用文档 - https://example.com/help`；多个按钮用 `&&` 分隔，不需要按钮时发送 `-`。
4. 检查预览并确认。

一条规则支持1–8个关键词，匹配其中一个即可；最多3个HTTPS按钮。按钮不能使用明文HTTP、脚本网址或包含账号密码的URL。

## 群内命令示例

```text
/addreply 帮助,教程 | 请先查看使用文档 | 使用文档 - https://example.com/help
/replies
/delreply 帮助,教程
```

示例域名需换成你的实际链接。群内媒体回复：回复已有媒体消息后发送 `/addreply 关键词 | 文字说明`，机器人保存并复用Telegram文件ID。

## 替换和删除

进入规则列表选择条目，按页面分步替换或确认删除。群内删除命令需提供同一组关键词，顺序可以不同。不同群的规则独立保存。

## 为什么没有重复回复

每人每条规则约60秒冷却；另有全群每分钟上限，初始20条，可调1–60。多人触发达到总限频后会略过，防止自动回复放大刷屏。

检查是否被内容防护先拦截、机器人是否能发送对应媒体、保存的文件ID是否仍有效。建议用普通成员账号在测试群验证实际触发。
