# 定时公告

**入口：定时公告。** 支持单次、每天或每周发送文字公告，每群最多20条任务。

## 创建步骤

1. 打开定时公告，选择单次、每日或每周。
2. 按提示发送时间；使用页面显示的时区，默认 `Asia/Shanghai`（北京时间）。
3. 发送标题和正文，标题最多60字，正文最多3500字。
4. 检查时间、群组和内容，确认创建。

单次时间必须在未来。每日和每周任务不需要每次重新创建。

## 命令示例

```text
/schedule daily 09:00 | 早安通知 | 欢迎交流，请遵守群规。
/schedule weekly mon 19:30 | 每周提醒 | 请查看本周公告。
/schedule once 2027-01-20 15:00 | 活动通知 | 今天下午开始活动。
/schedule list
```

使用单次示例时替换为实际未来时间。命令详情见[命令参考](../commands.md#定时公告)。

## 暂停、恢复和删除

点击任务详情，可暂停、恢复或确认删除。暂停保留任务配置，删除需确认。

```text
/schedule pause 1
/schedule resume 1
/schedule del 1
```

## 延迟与离线处理

发送可能比设置时间晚几十秒。Telegram暂时不可用时按1、2、4分钟等间隔退避重试；超过原计划6小时的任务会跳过，避免上线后集中补发。

创建者确定失去群管理身份时，任务暂停；短暂无法读取身份会退避重试。机器人收到发送成功后、写入本地记录前异常退出，极少数情况下可能重复发送，因此不用于要求严格一次发送的交易或账单通知。
