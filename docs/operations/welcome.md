# 欢迎消息与群规

**入口：欢迎消息。** 新群默认开启欢迎语，可编辑欢迎内容、群规和每分钟上限。

## 各功能有什么用

| 功能 | 开启或操作后的作用 |
| --- | --- |
| 欢迎消息开关 | 新成员加入时发送欢迎语；关闭后不发欢迎语，已有群规仍可查询 |
| 编辑欢迎语 | 修改新人加入时发送的内容，`{name}` 替换为新人的名字 |
| 编辑群规 | 修改 `/rules` 和成员菜单展示的规则；不会自动把这些文字变成违禁词或处罚条件 |
| 每分钟欢迎上限 | 限制欢迎消息数量，避免集中入群时机器人自己刷屏；超额消息直接略过 |

只开欢迎消息，会发送问候，不会限制新人发言或要求答题。需要答题时，另外开启[新人验证](../members/verification.md)。

## 编辑欢迎语

1. 打开欢迎消息，点击 **编辑欢迎语**。
2. 发送文字，例如 `欢迎 {name} 加入！请先阅读 /rules。`。
3. 检查预览并确认保存。

`{name}` 会替换为新人名字，内容最多1500字。群内也可使用：

```text
/welcome on
/setwelcome 欢迎 {name}！请文明交流。
```

## 编辑群规

点击 **编辑群规**，发送最多1500字的内容并确认。成员可通过 `/rules` 或成员私聊菜单查看。

```text
/setrules 请文明交流，禁止广告、诈骗和刷屏。
/rules
```

## 欢迎限频

新群默认每分钟最多10条，可调1–60。超出时略过欢迎语，不在稍后集中补发。验证题独立发送，不占欢迎额度。

例如最近60秒已经发出10条欢迎语，第11次欢迎会略过；待之前记录移出窗口后，再有新人加入才可能发送。欢迎语被略过不会跳过该新人的验证。

关闭欢迎语不会关闭新人验证或删除群规；各功能按自己的设置执行。
