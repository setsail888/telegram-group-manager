# 分类违禁词库与大词库管理

本版提供 **13类、6,566条去重词条**，分类内合计6,572条；少量词在不同分类重复。自定义违禁词和精确例外不再有300条总量限制，文件可分批追加，分页也取消原100页限制。实际规模仍取决于服务器内存、磁盘及首次构建耗时。

原创招揽分类由人工列出的短语及“对象+话术”组合展开，定义在 `app/wordlists/curated.json`；独立两字清单在 `short-words.json`。可下载的逐行TXT为 `curated_*.txt`。这不是从正式群消息训练得到的模型，也没有实测命中率排名。

公开数据来自 [fwwdn/sensitive-stop-words](https://github.com/fwwdn/sensitive-stop-words)，固定到提交 `a7d06bb1c321e669943b6841570d9da6dad8ce2b`，只引入广告、色情、涉枪涉爆违法信息三份分类，没有单独引入通用停用词或政治分类。上游原文及许可证保持原始字节；运行时做全半角/大小写等规范化、去重并保留2–80字词条。原始广告文件混有无关人名、政治及明显泛词，运行时额外排除24条，清单见 `app/wordlists/public_exclusions.json`；不会因为这些词命中该分类。URL、版本、SHA256见 `app/wordlists/sources.json`，许可证见 `app/wordlists/LICENSE-Apache-2.0`。更新工具只下载文本，不执行上游代码。原始文件的空白保留，不参与项目代码空白检查。

规则交互参考 [Rose公开的高级屏蔽规则](https://missrose.org/docs/anti-spam/blocklists/advanced/)；多关键词及精确规则也参考 [tg-spam公开说明](https://github.com/umputun/tg-spam)。没有可核验的 WeGroupCloneBot、GroupHelpBot、MissRose_bot 私有词库或命中率数据，因此不声称复制其词库或达到其效果。

## 按钮使用

1. 私聊机器人 `/start` → 选择群 → **违禁词 → 分类词库**。
2. 所有分类初始均为**关闭**。可以先点“定向分类全部先观察”（前六类），或只打开与本群有关的分类。
3. 进入分类可逐页查看词条，选择**关闭／仅观察／执行处罚**。查看变更预览后确认，启用处罚会再次核验删除消息权限。
4. 命中后在**智能反垃圾 → 防护记录**查看词条、分类和执行结果。观察只留元数据，不保存群聊全文，不增加累计处罚次数。
5. 分类中的词条可点击**排除**，也可从首页输入完整词条排除或恢复；仅影响当前群内置词库。需要更精细时，把同名词添加为自定义规则并选择整词或整句。

执行顺序和边界：

- 违禁词总开关关闭时，自定义和分类词库都不执行。全局内容过滤“仅观察”优先于分类处罚。
- 自定义同名规则覆盖内置词条。例如将某词设为“整句”，分类不会再按“包含”绕过该精度；排除内置词也不会停用同名自定义规则。
- 字面自定义命中优先；分类和变体中的“执行处罚”命中优先于“仅观察”。观察命中不会豁免同条消息的链接、转发或刷屏等独立违规。
- 精确例外仍只豁免“对应关键词+完整允许文本”，额外广告或另一规则不会被连带放行。包含式词库会命中引用，反诈、金融、医学、安全研究群尤其需要试用。
- 正文、图片说明和可见按钮文字共用规则。OCR继续保留可信度、至少四字、编辑失效和管理员保护；启用分类不会开启OCR或改变其模式。
- 分类默认使用规范化的字面包含匹配；可按下文单独开启中文变体。没有通用拼音模糊匹配、语义分类、二维码识别或自动解析短链。

## 两字词、繁简与同音绕过

原有「包含」并非整句精准匹配：添加 `刷单` 后，`警惕刷单骗局` 也会命中。新增**分类词库 → 两字短词（严格）**提供73个两字词，仍默认关闭。推荐先仅观察；不希望命中正常引用时，排除该内置词或设置完整文本的精确例外。

入口：**违禁词 → 中文变体识别**。四项分别选择**关闭／仅观察／执行处罚**，预览确认后持续保存。「十分钟有效」只限制确认请求，已保存设置不会十分钟后关闭。可先点“四项全部先观察”，再使用“测试关键词”并查看防护记录。

| 功能 | 示例 | 边界 |
| --- | --- | --- |
| 繁简字形 | `刷單返佣` → `刷单返佣`；自定义繁体规则也可匹配简体消息 | 只用固定字表的首个映射，不是完整OpenCC词组/地区转换，多义字仍可能误判 |
| 定向同音／拼音 | `唰丹返拥`、`SHUADAN返佣`、`刷dan返佣` → `刷单返佣` | 35组共153个已列出别名，不做整句拼音转换或任意编辑距离匹配；英文别名保留字母边界 |
| 拼音＋中文混写 | `shua单返yong`、`接ma平tai` | 已启用的包含词至少两个汉字，逐字完整拼音与中文混写；剩余汉字必须一致。不扩展整词/整句，不识别任意纯拼音或首字母；多音字取表中首音，数字声调暂不支持 |
| 上下文别名 | `菠菜平台` → `博彩平台`；`菠菜很好吃`不转换 | 易混词需同一分句、别名两侧各24字内有指定提示词；不跨换行、句号/问号/叹号/分号或按钮。只是规则线索，仍会误伤新闻和反诈引用 |
| 短词拆字增强 | `刷⭐单`、`刷*_*单` → `刷单` | 相邻汉字之间1–3个标点、空白、符号或组合标记；不跨换行或按钮，不删除夹杂字母/数字。过长间隔不合并 |

变体只增强**已添加的自定义包含词**和**已启用分类**。单开变体不会启用任何词库；“整词／整句”不扩展，同名自定义精度覆盖内置词。关闭违禁词总开关仍停止全部词库执行；全局观察优先。需要多个功能共同命中时，所需功能或分类任一为观察，该命中就只观察；同一消息另有能执行的规则，仍执行相应处罚。

完整混写操作及间隔、英文边界说明见[拼音＋中文怎么启用](moderation/variants.md#拼音中文怎么启用)。拼音模式与其他三项独立选择，升级后默认关闭，不改变现有分类设置。

正文、图片说明及每个可见按钮独立转换；例外使用**原始关键词 + 完整原文本**，例：启用对应变体后可添加 `刷单返佣 | 警惕唰单返佣`，不会连带放行简体版本、额外广告或其他关键词。测试入口与防护记录显示原规则及变体类型。OCR可使用繁简与定向别名，但仍要求至少四个字符、达到可信度，保留编辑失效和管理员保护；两字词不会因此进入OCR自动删除。

繁简字表来自 [OpenCC ver.1.1.9](https://github.com/BYVoid/OpenCC/tree/556ed22496d650bd0b13b6c163be9814637970ae)，保留原始 `TSCharacters.txt` 与Apache-2.0许可证，固定版本/URL/SHA256见 `app/wordlists/variant-sources.json`。别名与提示词为本项目可审查数据 `aliases.json`，不是其他机器人的私有词库。新增实际漏判时应补充别名及正常聊天反例，再测试上线。

拼音字表来自 MIT 许可的 [pypinyin 0.55.0](https://github.com/mozillazg/python-pinyin)，固定 PyPI wheel 的 SHA256，提取41,923字的首个读音生成本地表；保留许可证、版本及生成文件校验值，见 `app/wordlists/pinyin-source.json`。`scripts/update-pinyin-data.py` 只读取校验后的数据，不执行或安装上游代码。运行时不增加依赖、不连接翻译或拼音服务。

## 文件导入与导出

**违禁词 → 文件导入**，发送UTF-8文件或粘贴文字。单次文件最多 **1 MiB**，支持分批追加；并发大文件预览最多4份，避免占满小型服务器内存，这些限制不限制词库总条数。

支持三种格式，可以混用；空行和以 `#` 开头的注释忽略：

```text
# 每行一词，默认包含匹配
刷单返佣
```

匹配方式加Tab再加词条：`contains<Tab>词条`、`word<Tab>词条`、`exact<Tab>完整句子`，分别为包含、整词、整句；`<Tab>`应替换为实际制表符。JSONL每行一个对象：

```json
{"word":"contact","mode":"word","label":"英文联系词"}
{"word":"联系客服","mode":"exact"}
```

每个词规范化后需2–80字，`label`为可选显示名。`a+b`、`.*`等按字面文字处理，不执行正则。错误行、无效编码、同词不同模式冲突、过深JSON或无效Unicode会拒绝整批；不会保存一半。

预览展示新增/保留/文件内重复数量、模式分布、内容指纹和前12条样例。**已存在的词保留原标签及匹配方式**，不会被导入文件覆盖。确认前重新核验管理员身份、群组、预览消息和词库版本；若另一管理员修改词库，旧预览失效。确认只能使用一次，不会自动开启总开关或更改处罚。

**导出自定义词库**会在私聊发送JSONL，保留词条、显示名和匹配方式，可重新导入。每部分约900KB，有下一部分按钮；期间词库变化会要求重新开始，避免遗漏。导出不包含内置分类状态、排除词或精确例外；完整配置仍用数据库备份保留。

## 大词库性能与维护

文本与OCR关键词匹配使用无第三方依赖的多关键词自动机。文本热路径复用编译结果及本群规则快照；只有规则版本变化才重读词条。词条、模式、分类和例外修改通过SQLite触发器使缓存失效，另一个连接修改也能被发现。内置分类跨群共享自动机；缓存设有容量限制，首次编译或频繁切换大量大词库仍有成本。

本机 Windows Python 3.13.7 微基准：960字未命中文本、纯包含规则、预热后每组100次取3组最短值，10,000条约 **0.3129 ms/次**，50,000条约 **0.3103 ms/次**；同语义的预处理逐条子串参考分别约1.1641和5.8383 ms/次。50,000条首次编译约703 ms。该结果只衡量本机匹配函数，不含数据库、OCR识别、权限查询或Telegram网络，也不是群聊吞吐或命中率承诺。

变体需要额外转换与扫描；同机50,000条自定义词、全部13分类及三项变体均开启时，960字未命中热扫描约13 ms/次。首次构建还需额外索引时间；这是合成匹配测试，不代表真实群吞吐。变体索引惰性创建并复用，关闭时不构建，内置索引跨群共享。

```bash
python scripts/benchmark-wordlists.py
python scripts/build-wordlists.py
# 仅维护者需要：重取上述固定版本公开数据，不会跟随上游自动更新
python scripts/update-wordlists.py
python scripts/update-variant-data.py
python -m unittest tests.test_word_library tests.test_chinese_variants
```

升级前备份数据库，更新代码并重建容器。新增分类模式、排除词、规则版本表及防护记录字段为增量迁移，原设置、词条、积分、订单、活动与验证数据保留；不会替正式群自动开启新分类。本轮验证为离线API流程、临时数据库迁移和合成性能测试，真实群、真实OCR图片及服务器恢复仍需部署后验收。
